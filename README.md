# 567 神秘小旅行 · v19

宜蘭二日神秘旅程的手機網頁手冊，可直接上傳 GitHub Pages。
分享網址給旅伴，用手機瀏覽器「加到主畫面」即可像 App 一樣使用。

## 檔案結構

```
index.html          單頁式介面（首頁 / 行程 / 查詢）+ SVG 圖示定義
style.css           單一份樣式表，開頭是設計 token
app.js              名單資料 + 倒數揭曉 + 姓名即時篩選
sw.js               離線快取 + 版本控制
autoupdate.js       自動偵測新版本並強制更新
site.webmanifest    加到桌面時的 App 設定（直式、standalone）
browserconfig.xml   Windows 磚圖設定
assets/ icons/      主視覺與各尺寸圖示
```

## 上傳方式

1. 建立 GitHub repository。
2. 將本資料夾內所有檔案上傳到 repository 根目錄，確認 `index.html` 位於最外層。
3. Settings → Pages。
4. Source 選擇 Deploy from a branch，Branch 選 `main` 與 `/ (root)`。
5. 儲存後等待 GitHub Pages 網址產生。

`.nojekyll` 已包含。Service worker 需要 HTTPS，GitHub Pages 預設符合。

## 改版流程（重要）

改完任何檔案後，**必須同步更新三個地方的版本字串**，旅伴的手機才會抓到新版：

1. `sw.js` 的 `const VERSION = "..."`
2. `autoupdate.js` 的 `const BUILD = "..."`
3. `index.html` 裡 `style.css?v=` / `app.js?v=` / `autoupdate.js?v=`

命名建議：`567mystery-v20-20260810`（版號 + 日期）。目前是 `567mystery-v19-20260806`。

三處改成同一字串後 push，旅伴的手機在「開啟 App / 切回前景 / 每 3 分鐘 / 重新連線」任一時機會偵測到版本不同，自動清掉快取並重載。
若版本字串沒改，手機會沿用舊快取 —— 這是「明明改了卻看不到」最常見的原因。

## 上線前要做的事

行程頁底部的**測試面板**與 **RULE 提示**是開發工具。上線前：

1. `index.html` 刪掉 `▼▼▼ 上線前把這兩塊…` 到 `▲▲▲ 測試工具結束 ▲▲▲` 之間的內容
2. `style.css` 刪掉 `---- 上線前可整段刪除的測試工具 ----` 到 `---- 測試工具結束 ----` 之間的內容
3. `app.js` 刪掉 `▼ 上線前可整段刪除的測試工具 ▼` 到 `▲ 測試工具結束 ▲` 之間的內容

刪掉後行程頁會變成完整單畫面，倒數卡片自然撐滿。

## 設計規格

- 間距只用 4 / 8 / 12 / 16 / 24 / 32
- 字級只用 11 / 13 / 15 / 18 / 24 / 32 / 44（11px 是下限，不再有 6–9px）
- 圓角只用 12 / 16 / 24
- 字體兩套：標題 `Noto Serif TC`、內文 `PingFang TC`；Georgia 只用於數字
- 所有文字對比皆通過 WCAG AA（4.5:1，18px 以上 3:1）
- 觸控目標最小 44px
- 固定直式；橫向時顯示「請直立使用」遮罩

## 行程頁

- **倒數是主角**（44px），未解鎖時顯示三則線索
- **時間一到卡片自動翻開**，並停留 90 分鐘顯示店名、集合時間與導航按鈕；之後才接著倒數下一站
  （調整停留時間：`app.js` 的 `REVEAL_HOLD`）
- 卡片下方**七站時間軸**，已揭曉的站可以點回去複查地址，再點一次或按「回到目前進度」返回
- 線索目前是解鎖前三則一次全給。想改成隨時間一則一則出現，把 `app.js` 的
  `PROGRESSIVE_CLUES` 改成 `true` 即可，其餘程式不用動
- 倒數只更新數字節點，不再每秒重繪整張卡片；`aria-live` 移到獨立節點，讀屏不會每秒朗讀

## 資料維護

名單全部集中在 `app.js` 最上方，資料來源是 `567旅遊分房分車表.xlsx`：

- `people`：每個人的 `car`（車次）、`room`（房號）、`alias`（本名）、`kid`（分房表標「小」）
- `carLeader`：**車長依分車表標記**，不再用「名單第一位」推算
- `roomType`：各房房型
- `missions`：七站的解鎖時間、線索、謎底與 Google Maps 連結

### 對照 xlsx 後發現、需要你確認的兩件事

1. **第 7 車車長**：分車表標的是「陳彥朋（POTER）」，舊版程式取名單第一位而顯示成「蕭宇程」。
   v19 已依分車表改為 POTER。
2. **第 2 房房型**：分房表標「2+1房」，但實際住 4 人（郭仲凱、洪盈穎 2 大 ＋ 郭陳瑞、郭瑞芯 2 小）。
   房 1 同樣標「2+1房」但確實是 2 大 1 小。第 2 房可能應為「2+2 房」，需要你確認後改
   `app.js` 的 `roomType[2]`。
